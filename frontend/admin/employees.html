Important Import Requirements & Security
  • Mandatory Columns: Full Name and Email are strictly required. Phone Number and Username are optional supported fields.
  • Temporary Onboarding Password: Leave the Temporary Password column blank. The system will automatically generate a current-month onboarding password (Current Month) using Asia/Kolkata timezone.
  • Mandatory Password Reset: Employees onboarded with temporary credentials must create a permanent password upon their very first login.
  • Role Protection: Workbooks cannot grant Administrator or privileged permissions. All accounts are created with standard employee roles.
  • Duplicate Protection: Emails and usernames must be unique. The system validates against existing database records and prevents duplicate accounts.
